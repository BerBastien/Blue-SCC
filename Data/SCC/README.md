# SCC Data Directory

This directory contains input and output data for Social Cost of Carbon (SCC) calculations using the RICE50+ model with ocean damages.

## Directory Structure

```
Data/SCC/
├── in/                    # Input data (if any special SCC-specific inputs)
└── out/                   # SCC calculation outputs
    ├── ocean_data.parquet      # Combined ocean capital data for RICE50+
    ├── scc.csv                 # Main SCC results by year
    ├── country_level_scc.csv   # Country-level SCC breakdown
    ├── lhs.parquet             # Latin Hypercube Sampling parameters for MC
    ├── MC.parquet              # Monte Carlo analysis results
    └── scc.parquet             # Detailed SCC results (parquet format)
```

## Key Files

### ocean_data.parquet
Combined dataset containing all ocean capital parameters for RICE50+ model input:
- Coral reef values and damage coefficients
- Mangrove values and damage coefficients
- Fisheries/mariculture impacts
- Port disruption impacts
- Organized by country (ISO3 code) and ocean capital type

Generated by: `Code/SCC/make_input_data.py`

### scc.csv / scc.parquet
Main SCC results showing:
- Year
- SCC value (in 2020 USD)
- Broken down by ocean capital type (corals, mangroves, fisheries, ports)
- Broken down by valuation type (market, non-market use, nonuse)

### lhs.parquet
Latin Hypercube Sampling parameters for Monte Carlo uncertainty analysis:
- Parameter values for each MC iteration
- Includes normative parameters (discount rate, elasticity of marginal utility)
- Includes biophysical parameters (damage coefficients, climate sensitivity)
- SSP scenario assignments

Generated by: `Code/SCC/make_mc_bat_files.py`

### MC.parquet
Monte Carlo analysis results containing:
- SCC distributions across uncertainty parameters
- Sensitivity analysis inputs
- Results for each iteration and sectoral breakdown

## Workflow

1. **Generate ocean_data.parquet**: Run `Code/SCC/make_input_data.py`
   - Combines data from `Data/output_modules_input_rice50x/input_rice50x/`
   - Creates single input file for RICE50+ model

2. **Run RICE50+ model**: Execute GAMS runs (see `Code/SCC/SCC_steps.md`)
   - Produces GDX files in `Results/RICE50x/`

3. **Calculate SCC**: Use `Code/SCC/utils.py` functions
   - Reads GDX files from `Results/RICE50x/`
   - Calculates total and sectoral SCC
   - Outputs to `scc.csv` and `scc.parquet`

4. **Monte Carlo analysis**: Run `Code/SCC/mc_analysis.py`
   - Uses LHS parameters from `lhs.parquet`
   - Processes MC results from `Results/MonteCarlo/`
   - Generates `MC.parquet` with uncertainty distributions

## Data Format

All parquet files use pandas DataFrame format with standard column naming:
- Country codes: `iso3` or `n` (for RICE50+ region codes)
- Time: `t` or `year`
- Ocean capital types: `oc_capital` ∈ {coral, mangrove, fisheries, ports}
- Valuation types: `valuation` ∈ {consumption, usenm, nonuse}
